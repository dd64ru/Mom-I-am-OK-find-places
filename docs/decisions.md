# Decisions

1. **npm TypeScript workspaces with project references.** Five compilable modules, one request-driven backend. Android is a documented non-npm scaffold because choosing its package/certificates and implementing AIDL now would distract from the backend. No structural departure from the requested layout.
2. **Separate Discovery from Place.** Recognition cannot supply coordinates. Pending discoveries retain evidence; canonical places require WGS84 and confirmed status. This avoids exporting model guesses as navigation destinations. Confirming or auto-resolving based only on confidence is deliberately rejected.
3. **Direct official OpenAI OSS SIWC.** Dynamic public-client registration, PKCE/OIDC verification, per-profile issued client IDs, local protected files plus serverless Secret Manager sessions, cross-instance refresh serialization, account model discovery, public Responses streaming. API-key primary authentication and undocumented ChatGPT endpoints are rejected. The model is validated once per cold instance before first inference. Gemini is opt-in emergency fallback only for explicitly classified Responses HTTP 502/503/504 outages; broad fallback, ambiguous 429/500 responses and switching providers on setup/auth/schema errors are rejected.
4. **Serverless authenticated Telegram webhook.** Persistent GCE plus long polling was technically sound but had unnecessary fixed cost and operations for this small workload. Chosen: Functions v2 / Cloud Run scale-to-zero, `minInstances=0`, region `europe-west3`, strict secret-header/privacy gate and Firestore-backed album debounce/claims. A short in-request wait avoids Cloud Tasks infrastructure; retries drive recovery. No work after HTTP response. SIWC rotating tokens live in Secret Manager; a transactional lease and conservative interrupted-refresh marker prevent racing/replaying consumed tokens. No minimum warm instance, scheduler, VPC connector or permanent compute.
5. **Firestore owns data; clients read projections.** Server uses ADC/IAM. Firebase Auth UIDs control client reads. The configured private Telegram group authorizes human input separately; empty Firebase membership is valid. Timestamp strings and ordinary coordinate objects keep export adapters simple.
6. **Installed OsmAnd via a future AIDL companion.** Favor adding/updating an app-owned favorites group over embedding OsmAnd's full SDK or building navigation. Basic intents can open locations, but cannot be treated as durable favorite synchronization. Android remains documentation, not a pretend implementation.
7. **Bounded public venue verification.** SIWC web search supplies textual evidence/citations; replaceable Nominatim POI supplies authoritative WGS84 points. Public policy was rechecked: cache, global single-flight gate, 1.5-second spacing, fifty requests/day, visible OSM attribution, no bulk or generic search service. Missing/ambiguous results require city clarification, never invented points.
8. **Explicit transactional completion.** Discovery revisions and opaque Telegram token records separate interaction state from canonical Places. Confirm/cancel is one Firestore transaction; stable provider identities dedupe repeated screenshots while distinct branches remain separate. ForceReply ownership is temporary interaction control, not a configured user restriction.
