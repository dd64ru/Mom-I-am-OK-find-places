# Decisions

1. **npm TypeScript workspaces with project references.** Four compilable modules, one process. Android is a documented non-npm scaffold because choosing its package/certificates and implementing AIDL now would distract from the backend. No structural departure from the requested layout.
2. **Separate Discovery from Place.** Recognition cannot supply coordinates. Pending discoveries retain evidence; canonical places require WGS84 and confirmed status. This avoids exporting model guesses as navigation destinations. Confirming or auto-resolving based only on confidence is deliberately rejected.
3. **Direct official OpenAI OSS SIWC.** Dynamic public-client registration, PKCE/OIDC verification, per-profile issued client IDs, local protected files, refresh serialization, account model discovery, public Responses streaming. API-key primary authentication and undocumented ChatGPT endpoints are rejected. Gemini is opt-in fallback only.
4. **Single allowlisted Telegram poller.** Only images and `/help` or `/area` enter processing. Captions are ignored along with conversation to keep the privacy boundary simple. Albums use bounded debounce and sequential processing; crash-durable ingestion is deferred with the limitation documented.
5. **Firestore owns data; clients read projections.** Server uses ADC/IAM. Firebase Auth UIDs control client reads. Telegram IDs authorize input separately. Timestamp strings and ordinary coordinate objects keep export adapters simple.
6. **Installed OsmAnd via a future AIDL companion.** Favor adding/updating an app-owned favorites group over embedding OsmAnd's full SDK or building navigation. Basic intents can open locations, but cannot be treated as durable favorite synchronization. Android remains documentation, not a pretend implementation.
7. **No public POI service selected yet.** Search and geographic resolution interfaces serve the next implementation. Avoid choosing a country-specific provider or violating public OSM service usage policies just to make the initial demo appear resolved.
